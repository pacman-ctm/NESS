Experiments design:
- Split MNIST to 5 parts (each part with 2 digits, for example part i contains digit 2i and digit 2i+1, and all disjoint) so we can train for 5 continual tasks. I will denote each input part to be X_i (X_1 to X_5).
- Network: 1-linear-layer or 2-linear-layer

* Baseline: Continual training from scratch
* Our method:
- Init matrix X to be 0-matrix, initial weight W = 0-matrix.
- Fit W with the current dataset (X_1, Y_1)
- For i from 2 to n:
 + Concat X = [X_1 : ... : X_{i-1} ] (combined all the data from task 1 to task i-1)
 + Get U, S, Vt as the SVD of X
 + Get list of all sigma s_i as singular values from S and the u_i as the columns of U (respectively).
 + Let j to be the maximum s_i that is less than eps_1 = 1e-4.
 + Let U_span = span(u_j,..., u_d) with d is the shape of U (notice that everycase will have the same d = 784 if we play with MNIST).
 + Init trainable matrix W_tilde = 0-matrix (W_tilde.shape should make sure that shape(U_span @ W_tilde) = shape(W) )
 + Train W_tilde using SGD with the i-th task's data (X_i, Y_i) update W = W + U_span @ W_tilde
 + Evaluate with each of the previous outputs (Y_1,..., Y_i)
